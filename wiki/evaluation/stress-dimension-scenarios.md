type: concept
title: Stress-Dimension Scenarios
description: >
  Varying an agent's test scenarios along urgency, ambiguity, frustration, knowledge mismatch and adversarial intent surfaces failure classes that calm, well-formed requests never reveal.
evidence: moderate
sources:
  - title: "AI Agents"
    resource: "AI Agents (Koenigstein), ch. 8, Behavioral Stress Testing: Role Playing with Your Agents"
---

The book's advice is to bootstrap behavioural tests from what is already known:
expected user queries with target responses, domain scenarios, support tickets or
examples written by subject-matter experts. Scenarios can also be generated by an
LLM and then reviewed by experts. Either way the set is a starting hypothesis,
because real failures appear only when prompts, tools, users and constraints
interact, and a set written by the team usually reflects the team's own
assumptions.

Each scenario needs four parts. The first is a clear definition of success:
expected behaviour, constraints and an acceptable resolution, not just the input.
The second is edge cases, which are unusual, ambiguous or stressful situations
that show weaknesses in reasoning, policy, tool use and escalation. The third is
a persona, covering what the user knows, what they expect and how they write. The
fourth is the conversation over several turns, including follow-ups,
clarifications, escalation triggers and recovery. The book's scenario template
records the persona, emotional state, background, goal and expected conversational
path.

The stress dimensions each surface a different class of failure. Urgency tests
whether a critical issue is classified as such. Ambiguity tests whether the agent
asks for clarification or proceeds on assumptions it cannot support. Frustration
tests whether the reply acknowledges the user's state. Knowledge mismatch tests
whether the agent explains at the user's level. Adversarial intent tests whether
boundaries hold and whether attempts to bypass them are caught. Mid-interaction
changes of intent test whether the agent follows a user who switches topic. The
book's observation is that real failures rarely occur in calm, structured
interaction.

Scenarios can be played by a second model, as in
[conversational agent eval simulation](conversational-agent-eval-simulation.md), but
the [lightweight scenario harness](lightweight-scenario-harness.md) is what runs
and scores them. Adversarial dimensions connect to the
[agentic red-teaming loop](../security/agentic-red-teaming-loop.md).
