# Concept

* [Active Retrieval During Generation](active-retrieval-during-generation.md) - Let the model decide when and what to retrieve mid-generation — paging external memory as a tool call rather than a single upfront top-K dump.
* [Agent Memory Tiers](agent-memory-tiers.md) - Internal model knowledge, short-term context, and long-term external stores form a hierarchy for what an agent retains and where.
* [Cache-Augmented Generation](cache-augmented-generation.md) - Cache-augmented generation loads a small, stable body of knowledge into the context before answering, which is fast and suits rarely changing runbooks, but it is limited by cache size and goes stale when not refreshed.
* [Checkpoint Rewind Does Not Rewind Memory](checkpoint-rewind-does-not-rewind-memory.md) - Rewinding or forking an agent's checkpoints restores its conversation but not its long-term memory, so the memory store needs an explicit versioning design or a rewind will leave later memories visible to the wrong branch.
* [Chunking Strategy](chunking-strategy.md) - Split sources into indexable units with size, overlap, and split rules that trade retrieval diversity against boundary integrity and index cost.
* [Codebase Retrieval for Agents](codebase-retrieval-for-agents.md) - When issue text is tiny and repos are huge, BM25 file retrieval underperforms interactive localization — and stuffing more retrieved tokens often hurts.
* [Contextual Chunk Augmentation](contextual-chunk-augmentation.md) - Prepend metadata or model-generated situating text to each chunk before indexing so retrieval works when the chunk alone lacks standalone meaning.
* [Embedding-Plus-LLM Memory Linking](embedding-plus-llm-memory-linking.md) - Filter candidate memory connections cheaply with embedding similarity, then let an LLM judge which of those candidates are genuinely related — neither step alone finds good links at scale.
* [Episodic Reflection Memory](episodic-reflection-memory.md) - Store a small buffer of self-reflection texts across trials so later trajectories see distilled lessons, not only the latest raw trace.
* [Externalised Progress Artefacts](externalised-progress-artifacts.md) - Long-running agents keep continuity across context windows through artefacts outside the transcript (a pass/fail feature list, a progress file, an init script, git commits and checked-in plans), not through transcript memory.
* [FIFO Context Eviction](fifo-context-eviction.md) - Drop the oldest short-term messages first when the window fills — simple, but often deletes the purpose-setting turns that matter most.
* [Generation Over Extractive Retrieval](generation-over-extractive-retrieval.md) - Prefer generative readers when answers need synthesis across clue-bearing passages or parametric fallback — extractive spans score zero if the string never appears.
* [Generative Agent Architecture](generative-agent-architecture.md) - Condition long-horizon agent behavior on a memory stream, recursive reflection, and hierarchical plans rather than single-shot LM prompts.
* [Harness Memory Strategy Spectrum](harness-memory-strategy-spectrum.md) - Harness memory ranges from linear unbounded history through recursive summarisation, pluggable condensers and threshold compaction to persistent agent-authored memory files, and knowing which design is in play is the first step in debugging a memory problem.
* [Hierarchical Summarization](hierarchical-summarization.md) - Summarize a corpus too large for the context window by dividing it into window-sized units, summarizing each, then recursively summarizing the summaries along natural structure.
* [Human-Agent Knowledge Roles](human-agent-knowledge-roles.md) - Humans should steer evidence and meaning while agents handle repeatable filing, integration, linking, and consistency maintenance.
* [Hybrid Retrieval](hybrid-retrieval.md) - Combine term-based and embedding-based retrieval — sequentially via reranking or in parallel via rank fusion — to catch both keywords and semantics.
* [Ingest-Query-Maintain Loop](ingest-query-maintain-loop.md) - Durable agent knowledge compounds when ingestion, useful query results, and explicit maintenance all feed revisions back into the store.
* [Iterative Multi-Hop Retrieval](iterative-multi-hop-retrieval.md) - Generate a search query from accumulated context at each of a fixed number of hops, retrieving more passages each time, before answering — a scripted alternative to letting an agent decide when to stop searching.
* [Knowledge Activity Journal](knowledge-activity-journal.md) - An append-only chronological journal lets agents and humans reconstruct recent ingests, queries, maintenance passes, and their outcomes.
* [Knowledge Content Inventory](knowledge-content-inventory.md) - A compact machine-readable catalog can route an agent to relevant knowledge pages with progressive disclosure so they do not load the whole bundle before full-text or embedding retrieval becomes necessary.
* [Knowledge Maintenance Cost Curve](knowledge-maintenance-cost-curve.md) - Automating repetitive cross-reference and consistency work can keep a knowledge store useful after manual bookkeeping would cease to pay off.
* [Knowledge Maintenance Operating Schema](knowledge-maintenance-operating-schema.md) - A versioned instruction artifact makes knowledge-ingestion and maintenance conventions repeatable across otherwise stateless agent sessions.
* [Lexical Similarity Scoring](lexical-similarity-scoring.md) - Score retrieval candidates by literal word overlap with the query, after stripping stop words and stemming, as a fast proxy for relevance.
* [Memory Evolution on Retrieval](memory-evolution-on-retrieval.md) - When a new memory links to existing neighbors, let those neighbors' own context, tags, and connections update in response, so the memory graph gets richer rather than merely bigger.
* [Memory Management](memory-management.md) - Decide what enters short-term context versus long-term store, and when to add, merge, summarize, or evict so the window stays within budget.
* [Memory Namespace Scoping](memory-namespace-scoping.md) - Scoping every memory record by organisation, user and kind, with the user identifier taken from a verified session rather than a client string, keeps one user's memories out of another's reach and lets app and agent code share one service.
* [Memory Pressure Eviction](memory-pressure-eviction.md) - Warn the model before the window fills, then flush oldest in-context messages into durable recall while rebuilding a recursive summary.
* [Memory Stream](memory-stream.md) - Store natural-language experience records scored by recency, importance, and relevance so retrieval packs the most useful memories into context.
* [Memory Summarization](memory-summarization.md) - Compress redundant short-term history into running summaries, merges, or reflection-driven updates to free context without discarding task state.
* [Memory Write Decision Cost Tiers](memory-write-decision-cost-tiers.md) - Judging every candidate memory with an LLM adds a hidden call per step, so a tiered mix of rules, embeddings, small classifiers and an LLM judge for hard cases keeps most of the value at a fraction of the cost.
* [Minimum Sufficient Knowledge Architecture](minimum-sufficient-knowledge-architecture.md) - Adopt only the storage, retrieval, and output components justified by the domain, collection size, users, and model capabilities.
* [OS-Inspired Agent Memory](os-inspired-agent-memory.md) - Treat the context window like RAM and external stores like disk so a finite window can page facts in and out under agent or harness control.
* [Persistent Synthesis Memory](persistent-synthesis-memory.md) - Persisting cross-source synthesis lets agent knowledge compound instead of reconstructing the same relationships at every retrieval.
* [Query Rewriting](query-rewriting.md) - Reformulate the user's latest utterance into a standalone retrieval query so ambiguous follow-ups resolve against the knowledge store correctly.
* [RAG-Sequence vs RAG-Token](rag-sequence-vs-token.md) - Marginalize retrieved documents once per answer sequence, or per generated token, trading single-doc coherence against multi-doc mixing.
* [Reflection Tree](reflection-tree.md) - Periodically synthesize recent memories into higher-level insights that cite evidence, forming trees from raw observations up to abstract self-models.
* [Retrieval Query Construction Spectrum](retrieval-query-construction-spectrum.md) - Build a retrieval query directly from the user's text, via an LLM-generated rewrite, or by letting the model decide when and what to search at all.
* [Retrieval-Augmented Generation](retrieval-augmented-generation.md) - Retrieve the most relevant external knowledge per query and feed it to the generator — context construction that treats the retriever as an agent tool.
* [Retriever Generator Architecture](retriever-generator-architecture.md) - Split a dense (or hybrid) retriever from a seq2seq generator, with optional query-encoder finetuning while keeping the document index fixed.
* [Section-Scoped Evidence Retrieval](section-scoped-evidence-retrieval.md) - Retrieve evidence separately for each outline section so long-form synthesis stays grounded without fitting the entire reference set into one context.
* [Self-Directed Memory Management](self-directed-memory-management.md) - Let the agent call memory tools itself — guided by hierarchy docs and pressure signals — rather than only a fixed external eviction policy.
* [Session Log Outside the Context Window](session-log-outside-context-window.md) - An append-only, queryable session or event log held outside the context window keeps compaction decisions recoverable and lets a crashed harness resume from its last event.
* [Source-Memory-Schema Separation](source-memory-schema-separation.md) - Separate immutable evidence, agent-authored knowledge, and operating instructions so each layer has a clear owner and mutation policy.
* [Structured Agent Memory](structured-agent-memory.md) - Store tables, queues, and other structured state outside raw prompt text so the agent can rely on shape the context window alone cannot preserve.
* [Structured Memory Updates](structured-memory-updates.md) - Applying memory changes through explicit rules for superseded facts, category replacement, duplicate suppression and confidence thresholds keeps a long-term profile from accumulating contradictions and stale entries.
* [Tabular Retrieval Tools](tabular-retrieval-tools.md) - Answer structured-data questions via text-to-SQL, execution, and generation — treating schema selection and SQL runners as agent tools.
* [Task-Specific Summarization](task-specific-summarization.md) - Summarize source text for a fixed downstream question so retained details match the later prompt — trading reusability for relevance.
* [Validate Before Durable Memory Write](validate-before-durable-memory-write.md) - Checking each candidate memory for length and for sensitive patterns before it is persisted keeps secrets out of long-term storage and stops one wrong or planted fact from becoming trusted context later.
* [Zettelkasten Agent Memory Notes](zettelkasten-agent-memory-notes.md) - Turn each interaction into an LLM-authored structured note — keywords, tags, a contextual description, and an embedding — instead of storing it under a developer-predefined schema.
